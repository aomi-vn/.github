# Security policy

## Supported versions

Security fixes land on the default branch (`main`) of each Aomi repository. We do not maintain separate long-term release branches for marketing or pilot repos unless a runbook says otherwise.

## Reporting a vulnerability

Do **not** open a public GitHub issue for exploitable or sensitive findings.

Email **security@aomi.vn** with:

- A short description and impact
- Steps to reproduce or proof-of-concept
- Affected repository and commit or deployment target

We acknowledge reports within a few business days and coordinate disclosure with you.

## Safe harbor

Good-faith research that avoids privacy violations, service degradation, and data exfiltration is welcome. Do not access accounts or customer data you do not own.
